# Requirements, delegation and evidence

The detailed method is maintained in the separately selectable
`work-with-requirements` APM package in this repository. Install a published
release of `accelerate-toolkit/agent-context/packages/work-with-requirements`
using an explicit immutable release pin before adopting the method.

Its `define-requirements` skill carries the shared reference
`references/requirements.context.md`. The package also supplies decomposition,
verification planning, specification change, evidence assessment and
visualisation skills. Read the relevant installed skill for detailed work.

Context, Feedback loops and Trajectory remain in `org-meta-bundle`.
Existing requirement IDs, assignments, contract baselines and historical evidence
remain authoritative. Package installation does not change obligations or
complete migration. See the repository's `docs/sdlc-consolidation.md` for adoption.
